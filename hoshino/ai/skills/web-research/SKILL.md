# Web Research

针对一个主题做多来源调研，并交叉验证后给出带来源的结论。

## 步骤

1. 先用 `web_search` 搜索 2-3 组不同的关键词组合；
2. 对命中度高的页面用 `web_fetch` 抓取正文；
3. 对照多个来源，标注一致与冲突点；
4. 结论中附上来源链接与抓取时间。

## 规则

- 来源不足时不臆测，明确说明"公开信息有限"；
- 引用的信息必须来自实际抓取或搜索到的页面；
- 不确定的时效性信息标注"截至查询时间"。
